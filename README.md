# to-do-list-pa-apd-2026

Fitur minimum aplikasi:
1. Menu utama interaktif (main loop) & pilihan keluar (exit)
2. Struktur data python
3 & 4. CRUD
5. Searching
6. Sorting
7. Proses perhitungan sesuai studi kasus
8. Laporan/ringkasan data & transaksi
9. Validasi input
Pastikan program bisa berjalan dari awal sampai akhir.

- To do lists bisa dibuatkan folder
- To do lists bisa memiliki deadline
- To do lists bisa diurutkan berdasarkan:
    > Tanggal dibuat paling baru
    > Tanggal dibuat paling lama
    > Paling baru diedit
    > Paling tak pernah diedit
- To do lists bisa di-mark as urgent dan ditampilkan paling atas
- Pengguna bisa membuat goal mingguan (berapa banyak tugas yang ingin diselesaikan dalam seminggu).
- To do lists punya fitur rekap mingguan yang berisi:
    > Tugas terselesaikan
    > Tugas yg deadline-nya terlewat
    > Tercapai atau tidaknya goal mingguan
